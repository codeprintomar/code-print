# CodePrint Website

A responsive CodePrint studio website with Products, Projects, Services, Store, Updates, About, Contact, Links and a Firebase-backed admin dashboard.

See [`docs/SETUP.md`](docs/SETUP.md) for local preview, Firebase setup, Firestore security rules, Telegram notifications and deployment.

**No Firebase Storage is used.** The Store submits product requests; it is not a card-payment checkout.
