# تشغيل المتجر

1. **القواعد:** افتح Firestore → Rules وضيف البلوكات اللي في `docs/firestore.rules.txt` (الـ UID بتاعك مكان `YOUR_ADMIN_UID`) → Publish.
2. **Firestore Index:** أول مرة تفتح تاب "الطلبات" لو ظهر خطأ index، افتح اللينك اللي في الـ Console واضغط Create (ترتيب بالـ created).
3. ارفع الملفات: `store.html`, `assets/js/store.js`, `assets/js/admin.js`, `admin.html`, `site.css`, وباقي الصفحات (فيها لينك "Store").
4. افتح `/admin.html` ← تاب **🛒 المتجر**:
   - **+ منتج جديد** (مثلاً GradeOS بسعر 100) وحط الاسم والوصف.
   - **رابط التسليم (سري)**: لينك تحميل البرنامج (Drive/GitHub release...) — بيتحفظ في `private/secrets` ومحدش يقراه غيرك.
   - **إعدادات الدفع**: سطر لكل طريقة `InstaPay | اسمك@instapay` و `Vodafone Cash | 010xxxxxxxx`.
   - اضغط **💾 حفظ**.
5. **الطلبات:** العميل يختار المنتج، يحوّل الفلوس، ويكتب رقم العملية ← الطلب يظهر لك في تاب **📦 الطلبات** (مع زرار واتساب للعميل). راجع التحويل على تطبيقك ثم **✓ تأكيد الدفع وتسليم** ← العميل يفتح صفحة طلبه فيلاقي زرار التحميل.

## ملاحظات أمان
- الدفع يدوي (تحويل + تأكيد منك). ده أبسط حل من غير سيرفر، لكنه مش أوتوماتيك.
- رابط التسليم مش بيظهر لأي حد قبل تأكيدك، لكن بعد التأكيد أي حد معاه لينك الطلب يقدر يفتحه. لو المنتج ملفه مهم، استخدم لينك Drive "لأي حد معاه الرابط" وبدّله لو اتسرب.
- لدفع أوتوماتيك (Paymob / Fawry / Kashier) محتاجين Cloud Function — ممكن نضيفه كخطوة تانية.
